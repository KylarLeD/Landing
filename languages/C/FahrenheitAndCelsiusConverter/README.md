# Fahrenheit And Celsius Converter

## Overview
I am currently learning C so I decided to start by making this, its pretty simple but it took me a little to understand the scanf function.

This program converts fahrenheit to celsius and vice versa.

## What I Learned

1. **Basic C syntax**  
I learned how to make if statements, declare variables and do basic math in C.

2. **How the `scanf()` function works**  
The `scanf()` function is a function used to take input from a user.

3. **How the `while()` loop works**  
The `while()` function is used to repeatedly execute a block of code.
